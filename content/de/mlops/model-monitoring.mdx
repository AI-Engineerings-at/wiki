# Model Monitoring

Kurzreferenz zur Überwachung von ML-Modellen in der Produktion.

## Kernbegriffe

- Versionskontrolle für Modelle
- Promotion von Staging nach Produktion
- Monitoring und Alarme
- Sicherung der Datenqualität

## Bewährte Praxis

1. Modelle immer versionieren
2. Vor der Promotion testen
3. In der Produktion überwachen
4. Rückbauweg bereithalten
